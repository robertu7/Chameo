# Independent apps share the Chameo album

Chameo's Mac and mobile apps are independent peers: either app supports the complete daily practice without the other, and they are versioned and released independently. The Mac release continues to use the root `VERSION` file; the mobile Xcode project uses a checked-in mobile `.xcconfig` as the source of `MARKETING_VERSION` and `CURRENT_PROJECT_VERSION`. Neither release changes the other's version. Their only shared state is the user-selected Chameo album in Photos, which may propagate through iCloud Photos; preferences, reminders, permission state, onboarding, and capture-quality history remain local to each app. Both apps begin with the same default album name, but a custom album choice is not discovered or synchronized: the person must select the same name in each app's Settings, and split history is possible until they do. This avoids an application-level synchronization service while accepting Photos authorization and eventual iCloud propagation as the cross-device boundary.
