# Require iOS and iPadOS 18

The mobile Chameo app supports iOS and iPadOS 18 or later. Its universal target may use APIs available in iOS 18 without maintaining compatibility branches for older operating systems.

This reduces implementation and testing complexity for the first mobile release and establishes a clear device-support boundary. Devices that cannot run iOS or iPadOS 18 are intentionally unsupported; expanding support later requires a separate compatibility assessment.
