# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues. Use the `gh` CLI for all operations.

## Conventions

- Create, read, list, comment on, label, and close issues using `gh issue`.
- Infer the repository from `git remote -v`.
- When a skill says "publish to the issue tracker," create a GitHub issue.
- When a skill says "fetch the relevant ticket," use `gh issue view <number> --comments`.

## Pull requests as a triage surface

**PRs as a request surface: no.**

External pull requests are not included in the issue triage queue.
